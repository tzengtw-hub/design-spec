# SDD-000：起手式（網站標題與介紹文字）

- 狀態：已確認
- 建立日期：2026-11-01
- 相關決策：無

## 1. 為什麼要做
第 1 堂練習用：讓使用者第一次體驗「說一句話，網站就改了」。

## 2. 使用者會怎麼用
我想要把網站標題改成我的名字，所以我會請 Claude 修改標題和介紹文字。

## 3. 畫面需求
- 網頁最上方一個大標題、一段介紹文字
- 手機上字要夠大

## 4. 資料
無。

## 5. 不做的事
- 不加任何新功能、按鈕或區塊

## 6. 驗收條件
- [ ] 標題換成使用者指定的文字
- [ ] 介紹文字換成使用者指定的文字（如果有指定）
- [ ] 其他內容沒有被改動
