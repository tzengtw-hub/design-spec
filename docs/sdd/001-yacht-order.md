# 遊艇訂製網站　規格草稿 v0.1

> 狀態：草稿，待工程、專案、結構團隊會簽
> 範圍：客戶向船廠訂購遊艇時，從需求整理、法規對照到圖面審查的流程網站

---

## 0. 已確認的前提

| 項目 | 決定 |
|---|---|
| 使用者 | 兩種角色：客戶（船東）、船廠人員（業務／工程） |
| 船級社 | 只做 RINA Rules for the Classification of Yachts |
| 法規內容 | 船廠人工維護重點摘要，標註條文編號與規則版本，不放原文 |
| 圖面審查 | 第一版為固定範本清單，加審查意見與狀態紀錄，不做 AI 檢查 |
| 語言 | 繁體中文 |
| 平台 | 網頁（桌機、平板可操作），不做手機 App |

---

## 1. 要做什麼

**目標**：讓客戶與船廠在同一個網站上，把「需求 → 規格書 → 法規對照 → 圖面審查」串成一條可追蹤的流程。

### 功能 1：客戶需求整理成規格書

- 客戶透過分段表單填寫需求，內容包含：
  - 船長、船寬
  - 用途、航區
  - 乘客與船員人數
  - 動力與航速
  - 艙室配置
  - 設備選項
  - 預算與交期
- 系統把填寫內容整理成標準格式的規格書，可編輯、可存版本。
- 船廠人員可在規格書上加註意見，並標記為「客戶需求」或「船廠建議」。
- 可匯出 PDF（Word 視需求之後再加）。

### 功能 2：RINA 法規重點查詢與比對

- 資料庫收錄 RINA Rules for Yachts 的重點摘要，每筆包含：
  - 章節／條文編號
  - 適用條件（船長、船型、航區等）
  - 重點說明
  - 規則版本與生效日期
- 可用關鍵字或分類搜尋（結構、穩度、消防、機械、電氣等）。
- 可把規格書參數（例如船長、航區）與法規適用條件對照，列出可能相關的條文。
- 摘要由船廠人員維護：新增、編輯、停用，並保留修改紀錄。

### 功能 3：圖面審查檢查清單

- 依圖面類別提供固定範本清單（一般配置圖、結構圖、管路圖、電氣圖等）。
- 每個檢查項目可選擇結果：符合、不符合、不適用、待確認。
- 每項可填審查意見，並可連結到功能 2 的法規條文。
- 每份審查有狀態：草稿、審查中、已完成。
- 可匯出審查結果。

## 2. 畫面

| # | 畫面 | 使用者 | 說明 |
|---|---|---|---|
| 1 | 登入頁 | 全部 | 區分客戶與船廠人員 |
| 2 | 專案列表 | 全部 | 顯示專案名稱、船型、狀態；客戶只看到自己的專案 |
| 3 | 需求填寫頁 | 客戶 | 分步驟表單，可暫存 |
| 4 | 規格書頁 | 全部 | 預覽與編輯；右側為版本紀錄與意見欄；有匯出按鈕 |
| 5 | 法規查詢頁 | 船廠人員 | 搜尋列、分類篩選、結果列表；點開看條文重點與適用條件 |
| 6 | 法規對照頁 | 船廠人員 | 左側為專案規格參數，右側為可能適用的條文 |
| 7 | 圖面審查清單頁 | 船廠人員 | 選圖面類別後顯示清單，逐項勾選並寫意見，顯示審查進度 |
| 8 | 法規資料維護頁 | 船廠管理者 | 新增、編輯、停用條文摘要，查看修改紀錄 |

## 3. 不做的事（第一版）

- 不支援 RINA 以外的船級社（BV、ABS、DNV 等）。
- 不放 RINA 規則原文，也不做全文檢索，只放自行整理的摘要與條文編號。
- 不做 AI 自動檢索、自動判斷合規，也不做圖面 AI 檢查。
- 不判定「合規或不合規」的最終結論。系統只作輔助，最終判斷由工程師與船級社負責。
- 不做報價、合約、付款、線上簽約。
- 不做圖面線上標註（僅能上傳附件並寫意見）。
- 不做多語系切換，先以繁體中文為主。
- 不做手機 App，只做網頁（可響應式）。

## 4. 驗收條件

### 4.1 需求與規格書

- [ ] 客戶填寫完表單後，30 秒內可產生規格書預覽，欄位與填寫內容一致。
- [ ] 規格書每次儲存都產生新版本，可查看並還原。
- [ ] 可成功匯出 PDF，內容完整、中文無亂碼。

### 4.2 法規查詢與比對

- [ ] 搜尋關鍵字可在 2 秒內回傳結果。
- [ ] 每筆法規摘要都顯示條文編號、規則版本與生效日期，缺任何一項不能發佈。
- [ ] 規格書填入船長與航區後，對照頁能列出對應條文（以測試資料驗證至少 10 筆）。
- [ ] 管理者修改摘要後，系統留下修改人與時間。

### 4.3 圖面審查

- [ ] 每種圖面類別至少有一份可用的範本清單。
- [ ] 每個項目都能選擇狀態並填寫意見，意見可連結到法規條文。
- [ ] 所有項目都有結果後，才能將審查標記為「已完成」。
- [ ] 可匯出審查結果，包含項目、結果、意見、審查人與日期。

### 4.4 權限與一般

- [ ] 客戶無法看到其他客戶的專案，也無法進入法規維護頁。
- [ ] Chrome、Edge、Safari 在桌機與平板上都能正常操作。
