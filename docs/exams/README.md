# 考卷（Gherkin 驗收情境，講師準備）

這裡的考卷**不會自動執行**。要用的那一堂，在 Claude Code 說「收 Gherkin」加檔名，總管會把它複製進 `docs/features/`，之後每次改網站都會自動驗收。

| 檔案 | 哪一堂 | 對應規格 | 情境數 |
|---|---|---|---|
| `001-price-table.feature` | 第 3 堂 | `docs/sdd/001-price-table.md` | 8 |
| `002-currency.feature` | 第 4 堂 | `docs/sdd/002-currency.md`、`docs/adr/0001-exchange-rate.md` | 7 |

- 數字都來自 `docs/quotes/` 三份練習報價單（虛構）。
- 考卷用的字：供應商、單價、數量、運費、交期天數、總價；第 4 堂再加幣別（台幣／美金／歐元）和美金匯率。規格「畫面」段要用同樣的字，tester 才找得到欄位。
- 002 假設全班的 ADR 選「每次手動輸入當天匯率」。選了別的，請先改考卷再收。
- 講師已用一份參考網站實跑過：15 個情境全過；把運費拿掉，有 12 個情境會失敗。
